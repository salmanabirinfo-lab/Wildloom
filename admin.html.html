How to get an access token (one time)
  1. On GitHub, open your profile menu, then Settings.
  2. Scroll down the left menu to Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Press Generate new token. Give it a name like "Wildloom admin" and choose an expiry date.
  4. Under Repository access choose Only select repositories and pick your Wildloom repository.
  5. Under Permissions, open Repository permissions, find Contents and set it to Read and write.
  6. Press Generate token, copy it, and paste it above. GitHub shows it only once. Never share it with anyone.
